# Урок 10. Итоговый проект: банковская система

## Цель

Собрать всё изученное за курс в одну программу: ООП, интерфейсы,
исключения, коллекции, сортировки, файлы, меню.

## Что демонстрирует

| Тема | Где используется |
|---|---|
| Абстрактный класс (Урок 4) | `TAccount` — базовый тип счёта |
| Наследование (Урок 3) | `TSavingsAccount`, `TCreditAccount` |
| Инкапсуляция и свойства (Урок 2) | `Balance` — только для чтения |
| Исключения (Урок 5) | `TBankException` — свои ошибки |
| Интерфейсы (Урок 6) | `IPrintable` — единый вывод |
| Коллекции (Урок 7) | `List<TAccount>`, `Dictionary<String, TAccount>` |
| Сортировки (Урок 8) | `OrderBy` по балансу / имени |
| Файлы (Урок 9 + базовый) | сохранение и загрузка счетов |
| Меню | основной цикл программы |

## Что умеет программа

1. Создать счёт (обычный / сберегательный / кредитный).
2. Показать все счета.
3. Найти счёт по номеру.
4. Пополнить счёт.
5. Снять со счёта.
6. Перевод между счетами.
7. Показать историю операций по счёту.
8. Сортировать счета по балансу.
9. Сохранить в файл.
10. Загрузить из файла.
11. Выход.

## Архитектура

```
IPrintable (интерфейс)
     ↑
TAccount (абстрактный класс)
  ├── TDebitAccount      обычный счёт
  ├── TSavingsAccount    сберегательный (с процентной ставкой)
  └── TCreditAccount     кредитный (с лимитом)
```

- **`TAccount`** — базовый: номер, владелец, баланс, история операций.
- **`TDebitAccount`** — обычный счёт без ограничений.
- **`TSavingsAccount`** — с процентной ставкой; пополнение возможно,
  снятие ограничено.
- **`TCreditAccount`** — с кредитным лимитом (можно уйти в минус до лимита).

## Ключевые решения

- **`TBankException`** — свой класс исключения для бизнес-ошибок
  (недостаточно средств, счёт не найден, дубликат номера).
- **`Balance`** — свойство только для чтения. Изменение только через
  методы `Deposit` / `Withdraw`.
- **`List<TAccount>`** — основное хранилище.
- **`Dictionary<String, TAccount>`** — для быстрого поиска по номеру.
- **История** — `List<String>` внутри каждого счёта.

## Формат файла

Одна строка на счёт:

```
тип;номер;владелец;баланс
```

Пример:

```
debit;1001;Иван Петров;15000.00
savings;1002;Мария Сидорова;50000.00
credit;1003;Пётр Иванов;-3000.00
```
